## Obiettivo
Far interagire Python con il sistema operativo: preludio agli script di automazione per Linux, Docker e CI/CD.

## Concetti chiave
- `os.listdir()` restituisce solo **nomi**, non percorsi: per i controlli serve `os.path.join(percorso, nome)`.
- `os.path.isdir` / `isfile` per distinguere cartelle e file; `os.remove` è irreversibile; `os.system(cmd)` esegue un comando di shell.
- Prima di eliminare file: mostrare cosa verrà cancellato e chiedere conferma.

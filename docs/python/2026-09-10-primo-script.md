# Python — primo script (10/09/2026)

**Materia:** Python (docente: Massimo Papa) · **Cartella:** `Python/10-09-2026`

## Obiettivo
Verificare l'ambiente e lanciare il primo programma.

## Concetti chiave
- Un programma Python è un file `.py` eseguito dall'interprete (`python ciao.py`).
- `print()` scrive sullo standard output.

## Esercizio
`ciao.py` contiene una sola istruzione: `print("Hello World!")`.
